# Aikon makes things

A static project journal for [aikoned.github.io](https://aikoned.github.io), built with plain HTML, CSS, and JavaScript for direct GitHub Pages hosting.

## Project statuses

- **completed** — the project reached a finished or released state
- **wip** — the project is still active
- **archived** — development stopped before completion

Every project card includes a start date and either a finish date or an active status.

## Adding another project

1. Copy a `.project-card` in `index.html`.
2. Update the project number, dates, status, description, technologies, and links.
3. Set `data-status` to `completed`, `wip`, or `archived`.
4. Pick one of the existing card color classes or add a new color in `style.css`.

## Local preview

Open `index.html` directly, or serve the folder with any simple static-file server.
